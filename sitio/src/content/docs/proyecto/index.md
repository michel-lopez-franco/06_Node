A lo largo del curso construyes una **API de tareas y proyectos**. No es un ejercicio aislado:
cada módulo le agrega algo a lo que ya tienes.

1. **Básico:** una herramienta de línea de comandos que guarda tus tareas en un archivo.
2. **Intermedio:** una API REST con Fastify y PostgreSQL.
3. **Pro:** usuarios, TypeScript, tiempo real, seguridad y despliegue.

Cada etapa vive completa y ejecutable en `proyecto/etapa-NN-nombre/`. Si te atoras, puedes
empezar desde la etapa siguiente o comparar tu código con la solución:

```sh
diff -r mi-proyecto proyecto/etapa-02-persistencia-json
```
