Hasta ahora cada programa cabía en un archivo. Un proyecto real tiene decenas: cada uno se
encarga de una cosa y comparte con los demás solo lo necesario. En este módulo aprendes a
dividir tu código en **módulos**, a leer el código viejo que usa **CommonJS** y a manejar un
proyecto con **npm**: su `package.json`, sus scripts y sus dependencias.

Al final arranca el proyecto del curso: la **etapa 1**, una CLI de tareas hecha con varios
módulos.

## Al terminar este módulo podrás

- Exportar e importar funciones, clases y valores entre archivos con ESM.
- Reconocer código CommonJS y convertirlo a ESM.
- Crear un `package.json`, definir scripts y ejecutarlos con `npm run`.
- Instalar dependencias y explicar qué significan `^1.2.3` y `~1.2.3`, y para qué sirve el
  _lockfile_.
- Leer opciones de la terminal con `util.parseArgs`.
