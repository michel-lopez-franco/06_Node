En el módulo anterior ejecutaste JavaScript fuera del navegador. Aquí ves qué es Node y cómo
se comunica un programa con la terminal: los datos que recibe al arrancar (argumentos y
variables de entorno) y lo que devuelve al terminar (su código de salida).

Todo lo que ves aquí lo vas a usar en el proyecto del curso, que empieza en el módulo 3 como
una aplicación de línea de comandos.

## Al terminar este módulo podrás

- Explicar qué hacen V8 y libuv, y en qué se diferencia Node del navegador.
- Probar código en el REPL y ejecutar scripts con `node`, incluido el modo `--watch`.
- Leer argumentos de la terminal con `process.argv`.
- Configurar un programa con variables de entorno mediante `process.env`.
- Terminar un programa con el código de salida adecuado.
