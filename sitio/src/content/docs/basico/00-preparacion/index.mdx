Antes de escribir código en Node necesitas cuatro cosas: una terminal que sepas usar, Node
instalado en la versión correcta, un editor y una copia del repositorio del curso. En este
módulo las preparas y haces tus primeros dos ejercicios para conocer la forma de trabajo.

El curso funciona igual en **macOS, Linux y Windows**. Cuando un comando cambia según el
sistema, verás pestañas para elegir el tuyo. Si eliges una pestaña, las demás páginas
recuerdan tu elección.

## Al terminar este módulo podrás

- Moverte entre carpetas y ejecutar comandos desde la terminal.
- Instalar Node y cambiar de versión con un administrador de versiones.
- Clonar el repositorio del curso y mantenerlo actualizado con git.
- Ejecutar un ejemplo, resolver un ejercicio y comprobarlo con `npm test`.
