En este nivel usas **solo Node**, sin instalar dependencias externas. Al terminar sabrás ejecutar
scripts, organizar código en módulos, manejar asincronía, leer y escribir archivos y escribir
tus propios tests con `node:test`.

El proyecto arranca aquí como una **CLI de tareas** (etapas E1 a E3).

Consulta el [temario](../temario/) para ver los módulos de este nivel.
