## Objetivos

- Explicar qué es un _closure_ y qué variables recuerda.
- Escribir una función que devuelve otra función ya configurada.
- Guardar estado privado dentro de un closure.
- Comprobar que cada llamada a la función externa crea su propio estado.

## Explicación

### Una función que recuerda

Un **closure** (clausura) es una función que **recuerda las variables del lugar donde se
creó**, aunque ese lugar ya haya terminado de ejecutarse:

```js
function crearContador() {
  let cuenta = 0;
  return () => ++cuenta; // recuerda `cuenta`
}
```

`crearContador()` ya terminó, pero la función que devolvió sigue teniendo acceso a `cuenta`.
Nadie más puede leer ni cambiar esa variable: es **privada**.

Cada vez que llamas a `crearContador()` se crea una variable `cuenta` nueva. Dos contadores
nunca se estorban.

### Para qué se usan en Node

- **Fábricas**: funciones que crean funciones configuradas (`crearMultiplicador(2)`,
  `crearGeneradorDeIds('tarea')`).
- **Estado privado** sin clases, como un registro de mensajes que nadie puede borrar desde
  fuera.
- **_Callbacks_** (funciones que se pasan para que otra las llame después): en el módulo 4
  verás que casi todo el código asíncrono pasa funciones que usan variables de afuera. Eso ya
  es un closure.

## Errores comunes

**Todos mis contadores comparten la cuenta.** Declaraste la variable **fuera** de la función
fábrica, así que solo existe una. Muévela dentro, para que cada llamada cree la suya.

**`TypeError: contador is not a function`.** Guardaste la fábrica en lugar de lo que devuelve:
`const contador = crearContador` (sin paréntesis). Debe ser `crearContador()`.

**La cuenta se reinicia en cada llamada.** Declaraste la variable **dentro** de la función que
devuelves; se crea de nuevo cada vez que la llamas. Debe estar en la función de afuera.

**`ReferenceError: cuenta is not defined`.** Intentaste leer la variable del closure desde
fuera. Es privada a propósito: si hace falta, devuelve una función que la lea.
