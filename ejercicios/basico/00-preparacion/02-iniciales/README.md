# Iniciales

Completa `obtenerIniciales(nombreCompleto)` para que devuelva las iniciales en mayúsculas:
`"ana lópez franco"` → `"ALF"`.

- Ignora los espacios de más (al inicio, al final o repetidos entre palabras).
- Si el texto está vacío o solo tiene espacios, devuelve `""`.

Edita `solucion.js` y comprueba tu avance con:

```sh
npm test -- ejercicios/basico/00-preparacion/02-iniciales
```
