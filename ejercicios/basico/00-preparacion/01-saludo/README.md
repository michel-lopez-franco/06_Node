# Saludo

Completa `saludar(nombre)` para que devuelva `"¡Hola, Ana!"` cuando recibe `"Ana"`.

- Quita los espacios al inicio y al final del nombre.
- Si el nombre está vacío, tiene solo espacios o no se pasa, devuelve `"¡Hola, mundo!"`.

Edita `solucion.js` y comprueba tu avance con:

```sh
npm test -- ejercicios/basico/00-preparacion/01-saludo
```
