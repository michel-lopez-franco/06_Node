# Marcar completada

Completa `marcarCompletada(tareas, id)`. Recibe un arreglo de tareas
(`{ id, titulo, completada }`) y devuelve un **arreglo nuevo** donde la tarea con ese `id`
tiene `completada: true`.

- No modifica el arreglo original ni ninguna de sus tareas: la tarea que cambia es un objeto
  nuevo.
- Si ningún `id` coincide, devuelve un arreglo nuevo con las mismas tareas.

Edita `solucion.js` y comprueba tu avance con:

```sh
npm test -- ejercicios/basico/02-repaso-javascript/03-marcar-completada
```
