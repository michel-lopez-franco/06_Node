# Argumentos de usuario

Completa `obtenerArgumentos(argv)`. Recibe un arreglo con la forma de `process.argv` y devuelve
solo lo que escribió el usuario, sin la ruta de `node` ni la del script.

- No modifiques el arreglo que recibes.

Edita `solucion.js` y comprueba tu avance con:

```sh
npm test -- ejercicios/basico/01-que-es-node/01-argumentos-de-usuario
```
