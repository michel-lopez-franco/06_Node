# Sumar argumentos

Completa `sumarArgumentos(args)`. Recibe textos como los que llegan por la terminal
(`['2', '3.5']`) y devuelve su suma como número (`5.5`).

- Con la lista vacía devuelve `0`.
- Si algún texto no es un número (incluido `""`), lanza un error con el mensaje
  `"<texto>" no es un número`, por ejemplo `"abc" no es un número`.

Edita `solucion.js` y comprueba tu avance con:

```sh
npm test -- ejercicios/basico/01-que-es-node/02-sumar-argumentos
```
